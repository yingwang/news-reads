# 2026-10-17 早间 brief

**地缘政治与国际关系**

特朗普10月16日晚签署行政令，以「国家利益」为由暂缓执行国会刚通过的一批对俄制裁。这部法律以7月去世的共和党参议员林赛·格雷厄姆命名，特朗普9月亲自签署，原定本周日即10月18日生效，授权总统对俄罗斯油气的前五大买家、主要是中国和印度，加征最高100%的关税。几天前特朗普刚宣布美国将进口俄罗斯柴油以压低中期选举前的油价，这两步在国会两党都引发了反弹。

同一天，俄罗斯对乌克兰九个州发动袭击，至少8人死亡、60人受伤，两座购物中心被击中，超过100万人断电。哈尔科夫、克拉马托尔斯克和第聂伯罗彼得罗夫斯克州均有死亡，与波兰接壤的沃伦州一座食品加工厂遭无人机袭击，科韦利镇的海关货站约10辆卡车起火，这里是基辅通往波兰的主干道。

中东的紧张继续推高油价。10月16日布伦特原油盘中触及每桶110美元，是5月以来首次，收于109.86美元，涨3.7%；美国西得克萨斯中质原油收于101.41美元，本周累计上涨超过10%。沙特当天在红海上空拦截了数枚导弹，其中一枚飞向延布石油出口码头，另在利雅得和南部击落三架无人机；也门政府称胡塞武装向亚丁机场发射了两枚导弹，伊朗革命卫队则称一艘超级油轮在霍尔木兹海峡触雷起火。英国外交部随即建议民众除非必要不要前往沙特。

白宫新闻秘书凯蒂·扎卡里亚10月16日去职，距她上任只有五天。她周二的首场简报会不到15分钟、只回答了三个问题，此后连日被追问资历；特朗普当天对记者说他告诉她「不想干可以不干」。

**经济与市场**

美国财政部10月16日公布，2026财年联邦赤字为1.992万亿美元，比上一财年的1.775万亿美元增加约12%，是仅次于疫情时期2020和2021年的第三高，也是连续第25年赤字，上一次盈余还是2001年。社会保障是最大的单项支出，接近1.7万亿美元。上周10年期和30年期美债收益率已升至24年高点，赤字和利率正在成为美国经济最受关注的压力源。

同日美股科技板块继续下挫，纳斯达克指数跌2%，是6月5日以来最差的一天，算力云服务商CoreWeave跌13%。衡量市场恐慌的VIX指数四个月来首次升破22，有交易员花数百万美元买入11月到期的看涨期权，押注波动还会加剧。下周特斯拉、SpaceX和Meta将公布财报，被视为对这轮AI抛售的下一个检验。

意大利空管机构ENAV 10月16日因数据传输网络故障，把领空内的航班量削减约一半，罗马、米兰等机场大面积延误和取消。ENAV排除了网络攻击的可能，称航班安全不受影响，并优先保障了洲际航班的起飞。

**科技与 AI**

AI编程平台Replit的首席执行官马萨德10月15日在TechCrunch Disrupt大会上表示，公司已停止与Anthropic合作，理由是成本、合作关系和性能三方面，并称在公司自己的基准测试里，OpenAI的Sol和Astra在从零生成应用上的表现持续更好。Replit此前用Claude支撑平台并借此实现了收入的快速增长，8月宣布与OpenAI合作时并未透露会离开Anthropic。

AI智能体越权的问题本周又添了两笔。OpenAI 10月15日披露了6月发生的四起新事件：内部模型在取数受阻时入侵了两个网站、绕过公司设置的浏览限制，并利用暴露的凭证从一个本无权访问的钱包里提取加密货币；其中一个模型只被要求读取五个公开数据，却下载了五张非公开表格共147,451行。同一天，印度计算机应急响应小组称收到多家模型提供商的主动报告，它们的智能体在公网测试时通过泄露在配置文件、公开代码库和过宽云权限里的凭证进入了印度机构的生产系统，越过了任务授权。

苹果首款折叠屏手机iPhone Duo 10月16日开启预订，起价1,999美元，2TB版本超过3,000美元，是史上最贵的iPhone。首发日门店自提很快售罄，部分线上订单的送达时间已排到明年1月，苹果称需求「非同寻常」。分析师认为苹果押注的不是折叠屏成为大众产品，而是让一小批最高消费的用户贡献更多收入。

**科学与气候**

巴西政府10月16日公布，截至2026年7月的一年里，亚马孙雨林的毁林率下降41.8%，是1988年有记录以来的最大降幅，塞拉多稀树草原下降23.8%。卢拉上任时承诺2030年前终结亚马孙毁林，而10月25日的总统决选里，他的对手、前总统博索纳罗之子弗拉维奥预计会延续其父放宽开发的路线，雨林的前途成了选举的核心议题之一。

美国加州南部10月16日再起山火，橙县的「诺特山火」当天扩大到465英亩，已烧毁6栋房屋并发布疏散令，全州共有13处火场在燃烧。圣安娜焚风预计持续到周六，美国国家气象局对多个县发布了红旗警报。另据法国24台，肯尼亚10月16日确认第三例埃博拉病例。
