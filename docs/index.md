# 2026-10-13 早间 brief

**地缘政治与国际关系**

特朗普宣布的俄乌「能源停火」头一天就落了空。泽连斯基10月12日说，就在特朗普发帖后的几个小时里，俄军击中了乌克兰六处能源设施，伊久姆因电网被毁而停电，西部的能源和铁路设施也在夜间遇袭；俄罗斯外长拉夫罗夫同日表示，乌克兰「不配」得到停火带来的喘息。特朗普则坚称停火仍然有效，并为允许俄罗斯柴油进入市场的协议辩护，说「我做了正确的选择」，尽管两党都有议员表示反对。

胡塞武装对沙特的袭击已连续第三天，利雅得哈立德国王国际机场截至10月12日仍然关闭，多家航空公司停飞，有的停到本周末。美国联邦航空管理局10月11日深夜提醒美国航空公司在沙特及周边空域「谨慎飞行」，称风险可能涉及所有飞行高度，警告有效期至12月10日；沙特方面誓言作出「严厉回应」，胡塞官员则警告，美国若介入将遭到「迅速而痛苦的报复」。

英国首相伯纳姆10月12日在下议院说，有「强烈迹象」表明伊朗参与了9月27日英美共用的费尔福德空军基地外的安全事件，当时有五名英国公民因涉嫌恐怖主义和爆炸物罪被捕；英国已召见伊朗大使，并制裁两名个人，伊朗否认介入。同一天在美国，国土安全调查局的探员持司法部批准的搜查令，搜查了民主党众议员伊尔汉·奥马尔在华盛顿的住所，一名前官员称调查涉及移民欺诈指控，奥马尔则斥之为政治恐吓。另据10月12日披露，马斯克自7月以来向共和党团体捐款逾2.76亿美元，本选举周期累计约3.66亿美元，成为2026年中期选举已知最大的捐款人。

**经济与市场**

国际货币基金组织10月13日在曼谷年会期间发布《世界经济展望》，把2026年全球增长预测从7月的3.0%上调至3.1%，2027年维持3.4%不变，理由是人工智能带动的投资热潮抵消了部分能源冲击。不过它同时把2027年通胀预测从3.9%上调到4.1%，并预计霍尔木兹海峡要到明年3月才重新开放；研究部主任滕雷罗警告，全球经济的韧性「正在接近极限」，全球增长的95%如今只来自32个经济体，4月时还是54个。同期发布的《全球金融稳定报告》则把人工智能股票估值过高、举债增加列为金融体系风险偏高的原因之一，警告一旦崩盘可能波及全球市场。

这种担心当天就在亚洲股市上显现。10月13日，SK海力士跌逾8%，三星电子跌7.9%，双双创下8月以来盘中新低，软银集团跌8.03%，东京电子跌6.6%。起因是周一纳斯达克综合指数下跌0.44%、美光科技跌3.9%，投资者在评估中国长鑫存储周末宣布的新型存储芯片架构进展；有分析人士指出，中国厂商短期内在高带宽内存等先进产品上仍有技术门槛，眼下更多是获利了结。

**科技与人工智能**

Meta旗下的超级智能实验室10月12日发布Muse Wonder和Muse Wonder Full，这是该公司第一次推出前沿级模型。Meta在模型说明中称，二者的基准成绩与Fable 5.1、GPT-6 Astra相当；通过Meta的模型接口使用Wonder，每百万输入词元收费4美元、输出词元20美元，价位与业内同级模型持平。

联网设备的安全问题在同一天以两种方式浮出水面。巴黎检察院10月12日证实，一场「前所未有」的网络攻击远程控制了法国数百家超市的联网冷柜，把温度升到50摄氏度，造成食品损毁甚至起火，仅Intermarché就有约150家门店受害、冷柜升温持续六小时，法国国家网络安全局已介入调查。与此同时，Anthropic的前沿红队10月12日发布报告说，小型人工智能模型可能再过几个月，就有能力在智能电视、冰箱这类家用联网设备上自我复制；目前还没有哪个模型能可靠做到，但照趋势看，这样的模型很可能在今年底前出现，而且由于没有集中的宿主，一旦出现将很难关停。

**科学与健康**

厄尔尼诺带来的强降雨让阿根廷当局10月12日临时关闭伊瓜苏瀑布的游客通道：伊瓜苏河流量超过每秒12,000立方米，是平均水平的六倍多；园方随后表示流量逐步回落，10月13日重新开放。墨西哥太平洋沿岸则遭飓风西蒙和热带风暴雷切尔接连袭击，截至10月13日至少5人死亡，安全部队出动直升机救出数十名被困者。教皇利奥十四世将于10月13日入院，本周接受肺部结节手术。

**社会与文化**

在美剧《绝命毒师》中饰演小沃尔特·怀特的演员RJ·米特10月12日在得克萨斯州布朗斯维尔去世，年仅34岁，死因未公布。他本人患有脑瘫，多年来致力于推动影视作品中的残障人士形象；剧中饰演他父亲的布莱恩·克兰斯顿称他为「我亲爱的儿子」。同日，佐治亚州六旗游乐园的「歌利亚」过山车发生事故，造成一人死亡、多人受伤，六旗公司随即把旗下六座乐园的九台同类过山车暂时关闭。
