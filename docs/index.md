# 2026-10-19 早间 brief

**地缘政治与国际关系**

法国周末的骚乱后果比前一天的数字更重。截至10月18日，全国被捕人数已升至约2,400人，数百家商店被砸抢，多处公共建筑被焚，政府召开危机会议，媒体称之为「国家的巨大失败」。马克龙当晚发表电视讲话，称「没有任何理由」为暴力开脱，「看着这些画面，我们都在问，法国人怎么能对法国做出这种事」，并表示地方官员可视情况禁止部分街头集会；据法国24台，他拒绝了内政部长的辞呈。

乌克兰10月18日向俄罗斯发射了超过1,000架无人机，是开战以来规模最大的空袭之一。圣彼得堡州长别格洛夫称，圣彼得堡石油码头、鲁奇油库和科尔皮诺区的工业仓库起火，至少1人死亡、5人受伤，数栋民宅也被击中，当地主要机场一度限制运行。同一天特朗普在社交媒体上为暂缓对俄制裁辩护，称自己正在谈判和平，不想「愚蠢地把俄罗斯赶下谈判桌」，并指责泽连斯基「不想结束这场战争」。据《华尔街日报》10月19日报道，普京在10月9日与特朗普通话时曾提议举行他与特朗普、习近平的三方峰会来决定乌克兰战争的结局，地点可能是11月在深圳举行的亚太经合组织会议，泽连斯基不在其中；这一说法尚未得到证实。

中东方面，沙特利雅得99层的王国中心大厦10月18日通知所有租户即日起强制居家办公，「直至另行通知」，未说明原因，但正值胡塞武装对沙特的袭击不断升级，楼内租户包括国际货币基金组织的办事处和美林。海湾合作委员会当天谴责了胡塞的袭击。另一边，特朗普公开支持以色列总理内塔尼亚胡在10月27日的大选中连任。

加拿大阿尔伯塔省温赖特基地的火灾伤亡已经确认：总理卡尼10月18日说4人死亡，阿省省长史密斯称39人住院，其中至少19人情况危急。大火于10月17日下午4点在高强度战斗训练中燃起，时速96公里的大风助长了火势，卡尼称这是加拿大军队在和平时期本土发生的最严重悲剧之一。

肯尼亚10月18日确认第八例埃博拉病例，患者是一名49岁的病房杂工，负责清洗餐具和床单，很可能是被首例病人感染；据德国之声，疫情在刚果民主共和国也已扩散到第八个省。

**经济与市场**

中国国家统计局10月19日公布，第三季度GDP同比增长4.5%，高于路透调查预期的4.4%，也比第二季度三年来最低的4.3%有所回升；前三季度平均增长4.6%，处在官方4.5%到5%的目标区间内。增长主要靠科技产品出口，月度贸易顺差创下1,335亿美元的纪录，九月政府投资回暖止住了固定资产投资的下滑，而房地产低迷和消费疲弱仍在拖累。经济学人智库预计全年增长4.7%。

印度尼西亚雅加达综合指数10月19日暴跌超过5%，创2020年10月以来新低。导火索是明晟上周五提议把印尼直接从新兴市场降为「独立市场」，这可能让它被剔出主要的全球股指；高盛估算若被完全移出明晟新兴市场指数，被动基金将流出约56亿美元。明晟预计明年6月前作出最终决定。

日本首相高市早苗10月19日在国会否认「高市弱日元」和「高市高利率」的说法，称政府会通过建设强大的经济提升市场对日元的信心。她执政以来，日本国债收益率升至数十年高点，日元跌到1986年以来的最低水平，东京乃至华盛顿都曾入市干预。

巴西总统决选前一周，卢拉与弗拉维奥·博索纳罗10月18日举行了第一场电视辩论，双方多次互称「骗子」、互揭腐败丑闻；首轮弗拉维奥以47%对45%领先，决选在10月25日。捷克同一周末的参议院改选里，总理巴比什的执政联盟在27个改选席位中一席未得，亲西方的反对党拿下22席，继续掌控上院。

**科技与 AI**

Anthropic 10月18日宣布，将拿出公司5%的股份设立一个「公共利益基金」，用于资助非营利组织和应对AI对就业市场的冲击。这一举动发生在其筹备上市之际，市场预计估值可能超过1万亿美元；据报道，其招股文件写明AI可能带来「灾难性乃至生存性的风险」。

微软退出了英国最大的AI数据中心项目。据BBC 10月18日报道，Nscale去年承诺投资20亿英镑在埃塞克斯郡劳顿建设这座数据中心，微软原本要在那里出资建一台超级计算机，现已终止参与，原因与供电有关；Nscale表示仍会继续建设，并在寻找替代电源。

聊天机器人公司Character.AI本周申请破产后，迪士尼同意向至少60名员工发出聘用邀约，约占其员工总数的多数，预计年薪酬合计约6,000万美元。Character.AI前首席执行官阿南德此前已出任迪士尼首位首席技术官，迪士尼还以2,000万美元收购了该公司的部分资产。

**科学与气候**

日本宇宙航空研究开发机构的「火星卫星探测」任务计划于10月19日发射，目标是从火卫一上采集样本带回地球，预计2027年8月抵达。若能成功，这将是人类第一次从火星或其卫星带回样本，有望解开火星卫星的成因之谜。

挪威斯瓦尔巴群岛的朗伊尔城居民被告知不能再喝自来水。科学家认为，气候变暖让冻土融化，新暴露的基岩向城镇主要水源「冰塘」渗出重金属。这里距北极约1,300公里，升温速度是全球平均的五到七倍，秋季气温每十年上升可达4摄氏度，研究者警告其他北极社区也可能面临同样的问题。

教皇利奥十四世10月18日在梵蒂冈的窗口向圣彼得广场约1.5万名信众致意，这是他肺癌手术后第一次重要的公开露面，他说「微妙的阶段已经过去」，将逐步恢复工作。
