# 2026-10-14 早间 brief

**地缘政治与国际关系**

俄罗斯对基辅的空袭在「能源停火」宣布两天后仍在升级。泽连斯基10月13日深夜说，俄军用弹道导弹击中了为基辅供热供电的达尔尼茨卡第四热电厂和一栋居民楼，而且「事先没有得到伙伴国的预警」；基辅市长克利奇科称居民楼遇袭造成2人死亡、21人受伤，10月14日凌晨的密集导弹袭击又让基辅部分城区停电。与此同时，乌克兰无人机打进俄罗斯境内一百多公里。英国首相伯纳姆将于10月14日在唐宁街接待泽连斯基，表态「坚如磐石」地支持乌克兰；美国参议院一个跨党派小组同日呼吁特朗普撤销从俄罗斯进口柴油的协议。

沙特与也门胡塞武装的交火继续互相升级。沙特领导的联军10月13日夜间空袭了胡塞控制的萨那附近一处燃料库，胡塞武装随即向利雅得等城市发射导弹和无人机，联军称全部拦截、没有人员伤亡，但沙特阿美在东部城市达曼的一栋办公楼起火。胡塞方面警告下一步要打利雅得机场、阿美炼油厂和达曼总部；沙特内阁则表示胡塞「必将承担后果」。国际货币基金组织总裁说，这种你来我往的袭击「对所有人、所有地方都有潜在的负面外溢」。

德国汉堡法院10月14日开审「北溪」管道爆炸案，被告是一名只以「谢尔盖·K」相称的乌克兰前军官，检方指控他与其他乌克兰军人合谋炸毁管道、切断俄罗斯的天然气收入，他否认指控，这是2022年9月爆炸案四年来第一个受审的嫌疑人。另据俄方10月14日消息，《北海道新闻》一名记者（Yuki Imai）在萨哈林被以间谍罪起诉，俄方称他为东京搜集涉及俄军防御能力的情报，时间点正值普京8月登上争议中的千岛群岛之后日俄关系转冷。美国方面，白宫10月13日要求驻希腊大使金伯利·吉尔福伊尔辞职，此前有报道称她曾要求一名特朗普捐款人替她支付巨额信用卡账单以换取接触政府的机会，特朗普说「我不喜欢我读到的东西」。

**经济与市场**

中国海关10月14日公布，9月出口同比增长36.3%，是2月以来最快，进口增长31%，两项都大幅高于路透社调查的25.5%和24.5%的预期；对美出口增长近39.6%，当月贸易顺差升至2025年1月以来最高。值得注意的是，集成电路板出口金额激增136%，但出口数量只增加1%，说明涨的主要是单价；原油进口量则连续第六个月两位数下滑。

荷兰光刻机巨头阿斯麦10月14日公布第三季度利润超出预期，首席执行官富凯说，客户基于对人工智能投资规模和持续时间的判断，不断上调中短期设备需求预测，「有些客户已经表示有意下2029年甚至2030年的订单」。阿斯麦是全球唯一生产极紫外光刻机的公司，台积电等厂商制造最先进芯片都离不开它。

美国财政部10月13日对美国银行开出12亿美元罚单，指其未能发现潜在的洗钱和其他非法活动，漏报了超过50亿美元的可疑交易，其中10亿美元涉及国家安全和非法金融风险，包括可能与中国洗钱网络和美墨边境贸易洗钱相关的交易。同一天，摩根大通首席执行官戴蒙在财报电话会上说，不会允许外部的人工智能智能体进入银行系统代客户操作账户，「你不想要失控的智能体，而且可能有成千上万个」；该行已确认目前拦截外部智能体代零售客户操作。

**科技与人工智能**

美国司法部10月13日宣布，OpenAI一名35岁的沙特籍员工阿卜杜勒拉赫曼·阿尔福赞已于10月9日被联邦调查局逮捕，他被指在公司高管会议室里藏了一个「精密的录音设备」，用来秘密记录关于该公司「超级智能」技术的敏感讨论。OpenAI称设备在被植入几天后发现，此人已被解雇；他同时是一家中东风投机构的合伙人，此前在Meta、微软和SAP任职。

**科学与健康**

梵蒂冈10月13日发布医疗通报：教皇利奥十四世当天在罗马杰梅利医院接受了90分钟手术，切除了右肺下叶，术后确诊为肺腺癌。通报称手术成功、没有并发症，教皇醒来后已回到病房，预计住院约一周。这位71岁的教皇上周日刚向信众宣布体检发现肺部结节。

考古方面，据BBC 10月14日报道，考古学家在土耳其凯科瓦岛附近海底发现了世界上已知最古老的沉船，年代在4,400到4,700年前的青铜时代早期，大致与吉萨大金字塔同期。船体木结构已经腐朽，但所载的陶制储藏罐仍躺在海床上，有些里面还残留着当年装载物的痕迹；研究者判断这是一艘约10米长、往来地中海运货的商船。

**社会与文化**
