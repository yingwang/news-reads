# 2026-09-29 早间 brief

**地缘政治与国际关系**

美国与伊朗9月28日分别同卡塔尔调解方谈了一轮，这是结束这场持续七个月战争的又一次尝试。卡塔尔方面在纽约单独会见了伊朗外长阿拉格齐，也另外同美方接触，谈的是伊朗在联大提出的修订版停火方案：停止敌对行动、解冻伊朗资产、取消制裁，并在美方履约的前提下重开霍尔木兹海峡。与此同时，据彭博社报道，伊朗官员私下对在美国11月中期选举之前达成协议并不乐观。换句话说，接触在继续，但双方对时间表的判断差得很远。

俄罗斯对乌克兰的打击这几天明显瞄准了工业。据9月28日的报道，俄军一次袭击命中钢管企业 Interpipe，造成四人死亡、七人受伤；安赛乐米塔尔在乌克兰的钢厂在多次遇袭后仍无法复产。另有一架无人机落在基辅国立建筑大学附近，当时数百名学生正在上课。

法国极右翼的国民联盟在9月27日的参议院部分改选后，第一次在参议院凑够人数组成议会党团。距离2027年总统大选已不到一年，这是它在一向由传统政党把持的上院取得的突破。

**经济与市场**

美股9月28日周一收跌：道琼斯工业平均指数跌347.11点，跌幅百分之零点六七，报51,481.51点；标普五百指数跌百分之零点七七，报7,683.69点；纳斯达克综合指数跌百分之零点九二，报26,820.38点。压力主要来自债市，十年期美债收益率升6个基点至百分之五点二四，是2007年以来最高；三十年期升至百分之五点五六，为2004年以来最高。收益率一路走高，反映的是投资者对通胀和美国政府债务不断增加的担忧，他们要求更高的回报才肯持有美债。美伊谈判前景不明又推高了油价，布伦特原油仍在每桶一百美元上下，而二月底战事爆发前只有约72美元。

9月29日周二亚洲早盘跟着走低：日经225指数跌百分之一点二，报65,114.64点；韩国综合指数跌百分之零点六；香港恒生指数跌百分之零点五；上证综指与澳大利亚标普200指数微涨百分之零点一。澳大利亚储备银行预计今天加息，市场关注它如何描述通胀前景。

**科技与人工智能**

Anthropic 9月28日发布中档模型 Claude Sonnet 5.5，接替六月的 Sonnet 5。官方称它比前代快三成以上、完成同样任务的成本最多低三成，价格维持每百万输入2美元、输出10美元，支持一百万 token 的上下文。它也是第一个与 Opus、Fable 适用同一套网络安全防护的 Sonnet，因为其网络攻防能力已与 Opus 5 相当。这距离旗舰 Opus 5.5 发布只隔一周，Anthropic 还表示新的 Haiku 会在未来几周推出。换句话说，这一代模型的三个档位正在几周之内依次换代。

智能体安全仍是当天的另一条主线。据科技媒体汇总，佛罗里达州总检察长已向州法院申请紧急禁令，要求在缺少独立安全保障的情况下限制 OpenAI 的新模型开发，并对未成年人使用加以限制；英伟达则推出一套把权限约束放到硬件层面的智能体安全平台，思路是让模型本身无法越过文件、工具和网络权限的边界。

**科学与气候**

飓风「波罗」按墨西哥民防部门9月28日的预报，将以三级强度在当天傍晚登陆南下加利福尼亚州，周一早上最大持续风速约每小时115英里，预计降雨150到300毫米，随后越过加利福尼亚湾，于周二清晨在索诺拉州南部再次登陆。美国国家气象局提醒，它和此前的太平洋风暴「奥达利斯」带来的水汽，本周可能让美国西南部连降数日暴雨；通用汽车已暂停其科阿韦拉州工厂的生产。

欧洲航天局的木星探测器 JUICE 于9月28日第二次掠过地球，借地球引力调整轨道，继续飞往木星。另一项新研究发现，太空飞行在几周内就会改变肠道：食物移动变慢、菌群更多地分解蛋白质，这解释了宇航员常见的便秘问题。
