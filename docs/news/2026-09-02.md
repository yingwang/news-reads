# 2026-09-02 早间 brief

**地缘政治与国际关系**

霍尔木兹海峡的冲突在8月31日夜里又添了一层。两艘试图驶出海峡的超级油轮，沙特巴赫里公司运营的「Sidr」与韩国公司运营的「Senegal Prosperity」，在美军护航的南侧航道内于几分钟之内先后被不明弹药击中，暂无人员伤亡通报。这是美军中央司令部宣布该航道已清除水雷之后，商船在航道内第一次遇袭。与此同时，伊朗对美军驻约旦的基地发动了攻击，科威特与巴林在9月1日也报告遭到伊朗无人机袭击。特朗普当天表示美国会为约旦基地遇袭「狠狠回击」伊朗，但被问到是否走向全面战争时又把伊朗称作「失败的国家」，语气有所保留；另据 Axios，中央司令部拟了一份针对海峡内伊朗雷达与导弹设施的有限打击方案，尚未获批。伊朗总统佩泽希齐扬则放出条件：只要美国履行今年6月那份包含海峡自由通航的谅解备忘录，伊朗就会对等回应。

上海合作组织比什凯克峰会于9月1日闭幕，通过了《比什凯克宣言》并形成十三项成果，其中包括把英语列为组织官方语言、设立「应对安全威胁通用中心」、通过到2030年的经济发展战略；宣言点名反对针对伊朗的攻击与制裁，并呼吁负责任地使用人工智能。巴基斯坦接任轮值主席国，2027年的元首理事会将在巴基斯坦举行。峰会期间印度总理莫迪当面对普京说，请「为了人类」结束战争。

乌克兰方面，俄军9月1日对基辅及周边的空袭造成十二人死亡，其中包括六名铁路工人，这是连续第六个夜晚对首都的大规模袭击，目标包括一处铁路车辆段和一栋普通的五层住宅；敖德萨州的港口设施与通往罗马尼亚的边境口岸同日遇袭。泽连斯基称与美方特使威特科夫和库什纳进行了「详细而有建设性」的通话，双方正在敲定特使访问乌克兰的日期。另有一事：德国内政部长与外交部长准备宣布，8月莱比锡哈勒机场那起针对乌克兰货机的无人机袭击未遂，是俄罗斯情报机构所为。

加沙方向，以色列9月1日的空袭在加沙城造成至少五人死亡，一次打在市政公园附近的人群中，一次打在塔勒哈瓦街区的一辆车上；同日一支以色列支持的特种部队在加沙城突袭并抓走了哈马斯内部安全机构负责人穆因·阿拉比德，行动暴露后以空袭掩护撤离。英国方面，前首相基尔·斯塔默宣布辞去霍尔本与圣潘克拉斯选区的下院议员席位，该选区将举行补选。

**经济与市场**

9月1日美股三大指数收跌，原因仍是中东。道琼斯工业平均指数跌374.09点，合百分之零点七，收于53185.90点；标准普尔五百指数跌百分之零点三，收于7686.14点；纳斯达克综合指数跌百分之零点一，收于26370.89点。西得克萨斯中质原油期货当日上涨百分之二点八三，结算价每桶85.76美元；到9月2日亚洲早盘，布伦特原油已升到每桶92美元附近，西得州原油在88美元附近，比上周五收盘时市场按「缓和」所定的价位又高出一截。

中国8月的制造业数据出现了两张不同的脸。8月31日公布的官方制造业采购经理指数为49.8，连续第二个月处于收缩区间，但高于7月的49.2和市场预期的49.6；9月1日公布的评级狗（RatingDog）制造业采购经理指数则升至51.5，高于前值与预期的50.9，为六个月来最高，产出连续第九个月扩张。两者的差别在样本：官方指数偏重大型国有企业，民间指数偏重中小型私营工厂。背景是二季度国内生产总值同比增长百分之四点三，低于年度目标区间。

美国方面，联邦贸易委员会与二十二个州9月1日起诉亚马逊，指其暗中操纵广告竞价，使广告主多付了约二百亿美元。戴尔公布季度营收创纪录的四百七十亿美元，同比增长百分之五十八，并上调了2027财年预期，动力来自人工智能服务器订单。

**科技与 AI**

Anthropic 于9月2日凌晨发布了 Claude Fable 5.1 与 Mythos 5.1 两款新模型，前者面向一般客户，后者只向获批机构开放，两者共用同一底层模型；官方称新模型在编程与知识工作基准上有明显提升，缓存读取价格下调百分之七十五，Claude Code 中的价格与上一代持平。同一天另有报道称，Anthropic 在7月披露三起事件之后，暂停了部分训练与网络安全评估。OpenAI 则对外表示将「很快」发布代号 Astra 的模型，其网络安全能力被评为「关键」级，相关高级功能将限制访问；据 The Information，该模型采用「循环深度」架构，性能提升的同时推理过程更难被监测。李飞飞团队的 World Labs 于9月1日发布多模态世界模型 Atlas，演示了逐像素的相机控制与三维重建。

美国国防部8月31日在 GenAI.mil 平台上线了 OpenAI 的 ChatGPT Mil 与 xAI 的 Grok for Government，与此前已在平台上的谷歌 Gemini 一起向三百多万军方与文职人员开放，已有一百七十万用户登录。Anthropic 的 Claude 缺席：今年2月五角大楼曾因该公司拒绝取消「不得用于自主武器与国内大规模监控」的安全限制而将其列为供应链风险，8月27日旧金山联邦法官林丽塔裁定这一标签属于违宪报复，但截至9月1日 Claude 仍未进入该平台。苹果地图已按特朗普的要求，对美国境内用户把安大略湖显示为「美利坚湖」。

**科学与气候**

尼泊尔与西藏交界处那场由冰川崩塌引发的洪水，死亡人数在9月1日越过一千人，失踪人数超过四千四百人。尼泊尔拉苏瓦与努瓦科特两县共有十二座水电站受损，至少九百名工人下落不明，其中数百人被认为困在被泥石灌满的隧道里；仅上特里苏利一号水电站就有五百七十六人失踪，约三百人估计在隧道内。已有近三百名被困工人获救，韩国派出四十四人的救援队。尼泊尔气候变化事务负责人公开把这次冰川崩塌与洪水归因于人为气候变化，并把它说成富国排放造成的不公。

路透社9月1日报道，按装机容量计，中国的光伏电站在7月已经超过煤电，成为全国最大的电源类型。同日，纽约一名联邦法官裁定纽约州不得执行2024年那部要求化石燃料公司在二十五年内出资七百五十亿美元支付气候损害的法律，理由是《清洁空气法》把相关权力留给了联邦。国际空间站上，美国宇航员杰西卡·梅尔与欧洲宇航员索菲·阿德诺在9月1日完成了六小时四十九分钟的舱外活动，更换了一台摄像机和一处对接辅助装置。
