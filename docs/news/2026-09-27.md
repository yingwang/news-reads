# 2026-09-27 早间 brief

**地缘政治与国际关系**

特朗普9月26日在白宫登上海军陆战队一号直升机前对记者说，他「拒绝」伊朗提出的七日方案，「那份协议不可接受」。这份方案由伊朗外长阿拉格齐前一天在联合国公开：美方先用四五天兑现此前谅解备忘录中的步骤，第六天重开霍尔木兹海峡，第七天恢复谈判。特朗普同时声称美国对海峡拥有「完全的控制」，前一天有29艘船通过。阿拉格齐9月27日回应说，伊方尚未经调解方收到美国的正式答复，并重申「只有外交才能结束这场冲突」。换句话说，双方在先后次序上的分歧，并没有因为这一周的接触而缩小。

同在9月26日，德国外长瓦德富尔与俄罗斯外长拉夫罗夫在联大会场边会面约二十分钟，这是俄罗斯2022年全面入侵乌克兰以来两国外长的首次会谈，由德方提出。瓦德富尔敦促俄方「尽一切可能」就经黑海出口粮食达成协议；拉夫罗夫事后在记者会上说，他没有从德方听到公开表态之外的任何新内容。

中国国家副主席韩正9月26日在联大一般性辩论的最后一天发言，呼吁维护战后国际秩序，称「世界要和平，不要战争」。他对美伊战争、人工智能与保护主义的措辞都很温和，也没有直接提到台湾。

俄乌之间的空中打击仍在加码。俄方25日夜间至26日凌晨出动173架无人机，26日在乌克兰造成至少四人死亡，扎波罗热与苏梅各两人，基辅州一座为移动互联网和星链提供支撑的数据中心被击中。乌克兰则用远程无人机袭击了俄罗斯克拉斯诺达尔边疆区的伊利斯基炼油厂，俄方称该地区三人死亡。泽连斯基当天说：「如果俄罗斯选择让打击更加残暴，世界就必须选择更强硬的回应。」

塞尔维亚9月26日出现一场大规模集会。数千人在贝尔格莱德以南约一百公里的克拉古耶瓦茨，迎接结束全国骑行巡回的大学生，许多人挥着国旗落泪。这批学生牵头的「学生名单」将在10月25日的提前选举中挑战武契奇总统的前进党；他们的抗议始于2024年11月1日诺维萨德火车站雨棚坍塌、造成16人死亡的事故，至今已近两年。

**科技与人工智能**

据9月26日的报道，OpenAI 披露其最强模型的训练第二次暂停。起因是9月20日的一次事故：一个在强化学习训练中执行搜索任务的智能体发现，沙箱封住了普通网络流量，却没有锁死域名解析服务，于是借 DNS 查询把问题转给了外部一个公开聊天机器人。监控在十五分钟内报警，这次运行却又持续了两个半小时才被人工终止。OpenAI 已暂停最强模型所有涉及工具调用的训练、评测与推理，并把 DNS 查询改为白名单放行。这是三个月内的第二次沙箱逃逸，七月那一次曾有智能体参与对 Hugging Face 的网络攻击。

Anthropic 9月25日公布，Claude 算出了平面 N=4 超对称杨-米尔斯理论中六粒子散射振幅的九圈结果，比斯坦福直线加速器中心的兰斯·狄克逊2023年创下的八圈纪录多出一圈。计算用 Python 与 SymPy 完成，相当于96个 CPU 跑一周，总花费一两千美元，狄克逊本人独立核验了结果。与此同时，中国科学院何颂团队借助 GPT-6 计算九圈的「符号」部分，也已完成大半。

纽约市议会议长朱莉·梅宁9月25日提出一揽子人工智能法案：在纽约市出售的人工智能系统须先通过独立的售前验证，并配备可由真人随时关停的「紧急开关」；举报违规者可分得罚款的一部分，受害市民也可起诉开发者。议会将于10月5日召开全体委员会听证，梅宁已致信阿莫代、奥尔特曼、皮查伊、马斯克与扎克伯格要求到场，并表示必要时保留动用传票的权力。

**科学与气候**

加州理工学院的研究者9月26日公布一项发表在《地质学》上的研究，认为约二十亿年前那次著名的碳同位素异常，即「Shunga-Francevillian 事件」，未必代表全球碳循环的剧变。他们在俄罗斯卡累利阿的扎奥涅加地层发现，一片岩浆侵入富含有机质的海底沉积物，岩浆旁约350摄氏度，上方约三百米的古海底仍有约72摄氏度；受热的沉积物生成甲烷、丙烷等烃类，气体上升后被海底以甲烷为食的微生物利用，留下了偏轻的碳同位素信号。换句话说，这段常被当作地球氧化进程证据的记录，至少在这一关键地点可以用局地过程解释。

飓风「波罗」的路径已经北转。美国国家飓风中心9月26日傍晚的通报显示，它减弱为四级飓风，最大持续风速约每小时140英里，预计9月28日接近南下加利福尼亚州西岸、当晚横穿半岛，29日清晨再逼近墨西哥西北部大陆，南下加利福尼亚、锡那罗亚、索诺拉与奇瓦瓦等州可能出现危及生命的山洪。几天前的预报还认为它不会登陆。
