# 2026-09-24 早间 brief

**地缘政治与国际关系**

习近平9月23日傍晚六点前抵达华盛顿郊外的安德鲁斯联合基地，特朗普与第一夫人亲自到停机坪迎接，两架 B-1 轰炸机低空飞过。美国总统几乎从不去机场接来访的元首，这一次的礼遇比5月特朗普访华时北京给他的还高一档，那一回去机场的是国家副主席韩正。与迎接同时发生的是一条实质消息：财政部长贝森特9月23日宣布，中美同意把原定11月10日到期的「釜山协议」关税休战延长两个月，至明年1月10日。国事访问的正式欢迎仪式与国宴安排在24日，议题包括人工智能安全、台湾、伊朗战事与关键矿产。

联大一般性辩论进入第二天。伊朗总统佩泽希齐扬9月23日登台，开场先举起几张他说死于美国与以色列轰炸的儿童照片，随后指名道姓回应特朗普前一天「消灭」伊朗的说法：「我们愿意对话、外交和谈判，但不接受武力的语言。」他的结束语是：「他们确实打了我们，但我们没有屈膝。」同一天，委内瑞拉代总统德尔茜·罗德里格斯在联大承诺举行选举。

乌克兰方向有了一个新提法。泽连斯基9月22日在联合国总部与特朗普会面，表示只要俄罗斯停止打击关键基础设施，乌克兰愿意实行「能源停火」，并请特朗普促成他与普京的三方会晤，还希望特朗普在与习近平的会谈中谈到结束战争。9月23日他在联大发言时则强调，俄罗斯的收入「必须继续成为打击目标」。

人工智能第一次以这样的方式进入安理会。9月23日，OpenAI 的奥尔特曼、Anthropic 的阿莫代与 Hugging Face 的德朗格向安理会十五国作了通报，会议由法国外长巴罗主持。奥尔特曼主张走一条以人类控制和普遍受益为基础的「中间道路」；阿莫代则提议先达成几项窄而具体的协议：禁止借助人工智能研制生物武器、建立共享的评估体系、事故发生后互相通报。

**经济与市场**

美股9月23日普遍收跌：道琼斯工业平均指数跌百分之零点六三，标普五百指数跌百分之零点七三，纳斯达克综合指数跌百分之一点一一，罗素2000小盘股指数跌百分之一点六。压力来自债市：当天公布的采购经理人指数显示美国商业活动创五年多来最强，市场随之担心美联储还要加息，十年期美债收益率升至百分之五点一一左右，创2007年以来新高，五年期收益率盘中自2007年以来首次越过百分之五。标普五百的各行业里只有能源板块上涨。油价则继续走低，西得克萨斯中质原油收于每桶89.64美元，布伦特原油收于99.01美元。

**科技与人工智能**

Anthropic 9月23日公布了一项用模型做科研的案例：约九百五十个 Claude 智能体在二十一个小时里处理了约二亿一千万个词元，筛查了二十余万种逆转录酶，从中找出一类此前未知的噬菌体酶系统，研究者称之为「阵列相关逆转录酶」，并把二十个候选交给实验室验证。阿莫代的说法是，人选定了搜索的范围，大部分发现工作由 Claude 完成。

同一天，谷歌发布了 Gemini 3.8 Flash TTS 与 Flash-Lite TTS 两款语音合成模型，提供两千多种音色，三十秒录音即可复刻一个声音。阿里巴巴的通义团队则推出 Qwen Audio-3.1，一套含语音识别、语音合成与实时对话的五个模型，语音识别价格最多下调百分之九十五。

**科学与气候**

一项覆盖三百七十万瑞典人的研究9月23日发表，发现孕期经母体传给胎儿的几种罕见感染，也就是医学上统称为 TORCH 的那一组，与孩子日后患自闭症和智力障碍的风险显著升高有关。同日另一项追踪九万五千多人的研究发现，快速眼动睡眠越多，八十三种疾病的风险越低。

天文学家9月23日报告，首次在银河系之外发现一条由球状星团瓦解形成的恒星流，这为研究遥远星系里暗物质的分布提供了新的途径。气候这一侧，美国第二大水库鲍威尔湖9月22日跌到有记录以来的最低水位，原因是去冬异常干暖，科罗拉多河流域几乎没有积雪可以融化。
