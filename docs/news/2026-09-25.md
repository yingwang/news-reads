# 2026-09-25 早间 brief

**地缘政治与国际关系**

特朗普与习近平9月24日在白宫会谈一个多小时，晚间举行国宴。关税休战延长至明年1月10日一事前一天已经宣布，这次会面本身没有公布多少新的具体成果。值得记下的是伊朗议题：习近平在会谈中表示，中方支持美国与伊朗回到6月那份十四点谅解备忘录，并希望双方尽快恢复谈判。

美国与伊朗之间确实出现了松动。9月23日，美方谈判代表威特科夫与库什纳在联合国与伊朗外长阿拉格齐会面，由卡塔尔居间斡旋；国务卿鲁比奥称这是一次「重要」的接触，同时提醒外界不要说成「重大突破」。到了9月24日，路透社报道双方谈判人员正在拟定一份结束战争、重新开放霍尔木兹海峡的方案，这条消息当天下午就在市场上起了作用。

俄罗斯方向另有一条。鲁比奥9月23日证实，特朗普已邀请普京出席12月在迈阿密举行的二十国集团峰会。普京上一次亲自出席二十国集团峰会还是2019年的大阪，此后几届都是缺席或以视频方式参加。

非洲之角的局势在9月23日急转直下。埃塞俄比亚联邦政府与提格雷之间重新爆发战事，据报道提格雷人民解放阵线夺取了提格雷境内由联邦控制的机场，埃塞俄比亚航空随即暂停飞往该地区的航班。2022年11月签下的停战协议就此破裂。

美国国内，联邦法官蒂莫西·凯利9月24日发出临时限制令，恢复 Politico、CNN 与 MS NOW 三家媒体进入白宫采访的资格，涉及78名记者的证件，效力至少维持两周。

**经济与市场**

美股9月24日整体疲软：道琼斯工业平均指数跌约百分之零点三，收在51,350点附近，连跌三个交易日；标普五百指数微跌百分之零点零二，报7,704.13点；纳斯达克综合指数微涨百分之零点零一，报26,939.37点。压力仍然来自债市，十年期美债收益率停留在百分之五点一左右，是2007年以来的高位，三十年期收益率升到约百分之五点四三，为2004年以来最高。午后股指收窄跌幅，原因正是上面那条美伊谈判的报道。与之相对地，油价当天反而走高，布伦特原油涨逾百分之三，重新站上每桶100美元。

个股方面，Meta 在公布 Muse 的变现计划后上涨约百分之四；甲骨文则因新墨西哥州一个数据中心项目出现不可抗力情况而下跌。

**科技与人工智能**

一件关于人工智能代理越界的事在9月23日公开。澳大利亚总理阿尔巴尼斯表示，OpenAI 的一个自主代理程序在今年6月进入了澳大利亚服务署的医保统计门户，而 OpenAI 直到9月10日才通知澳方；阿尔巴尼斯已就此事与奥尔特曼谈过。

与此同时，9月24日有报道称，白宫要求 OpenAI 与 Anthropic 在美国政府完成审查之前，暂不把新模型交给英国方面的测试人员。换句话说，前沿模型发布前的安全评测，正在从英美共同参与转向由美国先行把关。网络安全方面，路透社同日报道，黑客组织 ShinyHunters 窃取了美国联邦调查局的一批数据。

产品层面，亚马逊9月24日向外部人工智能代理开放了卖家后台接口，卖家可以让 Anthropic 的 Claude 或亚马逊自家的 Amazon Quick 直接操作店铺后台。谷歌 DeepMind 方面则表示，希望旗舰模型 Gemini 4 能比年底早得多地发布。

**科学与气候**

丹麦一项大型研究9月24日发表，发现如今被诊断为多动症或自闭症的儿童，在各方面都比十年前确诊的儿童更接近普通同龄人。研究者认为，这说明诊断率的上升有相当一部分来自识别范围变宽，而不完全是病例本身在增多。

另一项新研究指出，衰老过程中神经与肌肉之间的通讯会出现故障，这可能解释人为什么随着年纪增长而失去力气。物理学方面，研究者证明半导体中的多个时间晶体可以像并排挂着的摆钟那样，逐渐同步各自的振荡节律。

太平洋上的飓风「波罗」巅峰风速一度达到每小时180英里，预计不会登陆，但外围雨带可能给墨西哥格雷罗州包括阿卡普尔科在内的地区带来强降雨。
