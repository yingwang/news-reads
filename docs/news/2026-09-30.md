# 2026-09-30 早间 brief

**地缘政治与国际关系**

美军于9月30日完成从伊拉克撤军，最后约1500名驻扎在库尔德地区埃尔比勒空军基地的官兵撤离，距2003年入侵伊拉克已有23年。美军曾在2011年撤出，2014年又为打击「伊斯兰国」返回，今年一月撤出了伊拉克大部分地区。伊拉克把这一天定为「主权日」。与此同时，美伊战争仍在继续，伊朗支持的民兵加紧袭击反对派据点和美军旧址；伊拉克原本承诺在9月30日前解除这些民兵的武装，现已请求把期限延到明年六月。换句话说，美军走了，伊拉克能否在没有美方防空的情况下自保，成了新的问题。

美国最高法院9月29日允许特朗普政府恢复「第三国遣返」，也就是把移民遣送到并非其原籍国的国家，推翻了联邦地区法院法官布莱恩·墨菲的禁令，三位自由派大法官表示反对。此案将于12月进行完整的口头辩论。在此之前，墨菲法官曾三次以程序正当性为由叫停这一做法，而政府已经用它遣送了数以万计的人。

据9月29日的报道，习近平上周访美期间与特朗普同游国家档案馆时，原定展出的1951年《旧金山和约》在中方反对后被临时撤下，原因是这份和约没有确定台湾的归属。这件小事说明，即便在一次以成果为主调的国事访问里，台湾问题仍是双方最敏感的一处。

另有一事值得记一笔：迪拜航空一架从迪拜飞往特拉维夫的 FZ1073 航班9月30日发出求救信号，紧急降落在沙特阿拉伯塔布克，正副驾驶受伤住院，乘客均安全，原因尚未公布。

**经济与市场**

美股9月29日周二小幅收低：标普五百指数跌百分之零点一七，报7,670.84点；道琼斯工业平均指数跌百分之零点二六，报约51,350点；纳斯达克100指数则涨百分之零点二一。十年期美债收益率升1.9个基点至百分之五点二五五，盘中一度触及百分之五点二九一，为19年来最高；三十年期收益率升至24年来的高点。当天公布的数据偏弱：8月职位空缺降至五个月低点，9月消费者信心跌到12年低点。拉住跌势的是两件事：原油当天回落约百分之三；纽约联储主席威廉姆斯表示美联储「可能」只需再加息一次，市场对10月加息的押注随之从百分之七十降到百分之五十二。

9月30日公布的8月个人消费支出物价指数（PCE）低于预期：整体同比上涨百分之三点四，预期为百分之三点七，7月为百分之三点七；剔除食品和能源的核心 PCE 同比上涨百分之三点零，预期为百分之三点三。数据公布后，美股三大股指期货转涨约百分之零点三，十年期收益率回落到百分之五点二三，10月加息概率降到百分之四十七。不过油价仍在高位，布伦特原油9月30日亚洲时段涨百分之一点四，报每桶97.49美元。

特朗普政府9月28日宣布放宽汽车燃油经济性标准：到2031年的目标由拜登政府定下的每加仑50.4英里降到约35英里，每年的提升幅度也从约百分之二降到最多百分之一。政府称这能让每辆新车便宜约1,300美元；批评者则认为，油耗更高会让车主在加油站多花钱，也会让美国车企在电动车上进一步落后于欧洲和中国。

**科技与人工智能**

特朗普9月29日在白宫宣布，Anthropic、谷歌、Meta、OpenAI、英伟达和 xAI 签署了一份自愿的「自我监管」协议，内容包括四项：建立健全的内部控制、聘请独立的外部审计机构核查、由董事会层级的委员会审阅审计报告，以及日后可能把这些做法写入法律。特朗普在会上说自己「绝不会扼杀这项技术的增长」，Anthropic 首席执行官阿莫代伊则表示这项技术「有非常真实的风险」。政府同时推出了面向公共服务的聊天机器人 America.gov。

OpenAI 同一天举行开发者大会，发布中档模型 GPT-6.1 Sol，称其智能接近旗舰 GPT-6 Astra，价格却只有五分之一：每百万输入 token 2美元、缓存输入0.10美元、输出10美元，与 Anthropic 前一天发布的 Sonnet 5.5 定价相同。另一项重点是名为 Dots 的常驻个人智能体：它由 GPT-6 Astra 驱动，可以接入 Slack、Teams 和 GitHub，并调用 Codex 写代码，当天向 ChatGPT Pro 和企业用户开放。此外还有一个每秒约300 token 的「超快」模式，价格是标准的六倍。

**科学与气候**

飓风「波罗」9月29日周二早上在墨西哥南下加利福尼亚州登陆，最大持续风速每小时110英里（约177公里），随后越过加利福尼亚湾并减弱为热带风暴。它带来的水汽让美国西南部普降暴雨：新墨西哥州多条公路被淹，林孔、哈奇等地因担心水坝溃决下令撤离；亚利桑那州出现多起水上救援；犹他州锡安国家公园一带发生山洪。这一地区一年的降雨量通常不到十英寸，所以短时间的大雨尤其容易成灾。

美国核管理委员会9月29日向田纳西河谷管理局颁发了田纳西州橡树岭克林奇河厂址的建造许可，这是美国第一张 BWRX-300 小型模块化反应堆的建造许可，单堆功率300兆瓦。此前加拿大安大略电力公司已在2025年拿到同型反应堆的建造许可。
