# 2026-09-26 早间 brief

**地缘政治与国际关系**

伊朗外长阿拉格齐9月25日在联合国大会期间公开了一份结束战事的「七日方案」：各条战线（包括黎巴嫩）先停火，美国解除海上封锁与石油制裁、释放被冻结的伊朗资产，第七天结束时重新开放霍尔木兹海峡，随后再恢复包括核问题在内的谈判。美方的态度并不买账，国务卿鲁比奥依旧不认为这是突破，华盛顿希望把核问题从一开始就放进同一个一揽子协议，而不是排在最后。同一天，巴基斯坦总理夏巴兹·谢里夫在联大发言中强调了巴方在美伊之间的斡旋角色。换句话说，双方已经开始谈先后次序，但分歧恰恰就在次序上。

俄罗斯9月25日白天对基辅发动无人机袭击，据最新统计造成七人死亡、五十七人受伤，其中包括儿童；一栋办公楼被直接命中，乌克兰最高司法委员会的行政楼也受损。与此同时，安赛乐米塔尔通知乌克兰政府，其在该国东南部的钢厂在五周内遭到四次打击、五名工人遇难，已无法「安全且可持续地」运转，这家乌克兰最大的钢铁企业因此停产。

埃塞俄比亚的战事在9月25日继续扩大。提格雷人民解放阵线称这是一场「防御性战争」，目标是推翻总理阿比；冲突已蔓延到相邻的阿姆哈拉州与阿法尔州，据报道当地电信与互联网在当天中断，外界担心停电与封锁会接踵而至。2022年结束的那场战争估计造成约六十万人死亡，此次重燃还可能把厄立特里亚卷进来。

**经济与市场**

美股9月25日收高，结束了动荡的一周：道琼斯工业平均指数涨478.64点，涨幅百分之零点九三，报51,828.62点，终结了此前三周的连跌；标普五百指数涨百分之零点五一，报7,743.41点；纳斯达克综合指数涨百分之零点四八，报27,068.72点，三大指数全周均录得上涨。推动因素之一是美伊谈判的消息压低了油价，美国西得克萨斯轻质原油跌百分之二点三三，报每桶92.41美元，布伦特原油回落到98美元以下。

压力并没有消失。十年期美债收益率当天仍在百分之五点一八的高位；密歇根大学九月消费者信心指数降到48.1，低于八月的51.7，受访者普遍提到油价高企与关税升级。个股方面，Meta 因推出人工智能代理 Muse，一周累计上涨约百分之十三；耐克则被美国银行下调至「跑输大盘」评级，目标价降到30美元，今年以来股价已跌约百分之四十三。

**科技与人工智能**

美国哥伦比亚特区联邦上诉法院9月25日以二比一裁定，五角大楼可以继续把 Anthropic 列为「供应链风险」，从而把 Claude 模型从国防部系统中移除、禁止其产品用于国防部业务。这场争端始于二月，起因是 Anthropic 拒绝放宽对大规模监控与自主武器用途的限制。合议庭暂缓了裁决的生效，给 Anthropic 申请重审或全院重审留出时间；此前加州一名联邦法官在另一宗案件中认定五角大楼的做法违法，两地判决方向相反，这件事最终可能走到最高法院。

同日，微软发布了重新设计的 Copilot，围绕三样东西展开：把对话与协作合并在一起的起始页「Home」、用自然语言搭建应用和自动化流程的「Code」，以及不必等人下指令就会自己动手的常驻代理「Autopilot」。其中 Autopilot 本月底进入私测，Code 年内向 Microsoft 365 付费用户开放预览。

编程代理这条赛道的收入也在快速放大。据彭博社9月25日报道，开发编程代理 Devin 的初创公司 Cognition 年化收入突破十亿美元，而四个月前还在约四亿九千万美元，几乎翻了一倍。

**科学与气候**

联合国大会9月24日通过了第一份关于海平面上升的宣言，目的是把各国分散的应对行动，变成持续、协调且有充足资金支持的国际行动。秘书长古特雷斯在会上说，世界不能「任由国家和文化消失在海浪之下」。这一周的联大发言中，许多国家都谈到了气候变化带来的损失，与之相对地，美国总统特朗普仍多次称气候变化是骗局。
