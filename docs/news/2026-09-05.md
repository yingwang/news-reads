# 2026-09-05 早间 brief

**地缘政治与国际关系**

俄罗斯9月4日下午把一架无人机直接打在基辅市中心的乌克兰安全局总部大楼上，地点在弗拉基米尔街，正对着圣索菲亚大教堂。袭击发生在当地时间下午三点半前后，造成十二人受伤，这是四年半的战事里安全局总部第一次被击中。泽连斯基说那架无人机是冲着安全局局长奥列克桑德尔·波克拉德的办公室去的，波克拉德当时不在里面；他随后要求安全局准备一次对等而且可感知的回应，并说打击的地理范围已经定下来。这一击同时说明了两件事：俄方开始点名打击乌克兰情报机构的首脑，而乌方的防空缺口已经大到让首都市中心的要害建筑暴露在外。

德国萨克森-安哈尔特州将在9月6日举行州议会选举，两百万选民有可能把德国选择党送进战后第一个由极右政党主导的州政府。该党的领衔候选人乌尔里希·西格蒙德在民调中领先，一旦当选就是联邦德国历史上第一位选择党籍的州总理。他的竞选方式值得注意：从新冠期间开始经营 TikTok，如今账号有超过八十万关注者，接近这个小州合资格选民总数的一半，他依靠的是平台上的传播力而不是政党纲领。德国多个州的国内情报机构已经把选择党定性为右翼极端主义组织。

以色列国家安全部长伊塔马尔·本-格维尔9月4日提出设立一个新的政府部门专门管理巴勒斯坦人的移民事务，并给出了具体规模：第一年二十五万人，七年内一百九十万人。几乎同时，美国众议院以二百三十七票对一百六十九票通过一项法案，取消对抵制以色列的高校的联邦拨款，其中三十三名民主党议员与共和党一起投了赞成票，众议员拉希达·特莱布称这是对言论自由的攻击。欧洲这一侧，丹麦、奥地利、德国、荷兰与希腊五国就一套共同的遣返中心模式达成一致，首批协议预计在2027年元旦前后签署。

美国国内有两件与十一月中期选举直接相关的事。密苏里州最高法院一致裁定阻止共和党在十年期中重新划分国会选区，新选区图不能用于十一月的选举。与此同时，联邦地区法官因迪拉·塔尔瓦尼就特朗普政府限制邮政系统投递选票的做法发出警告，称这会造成大规模的选举权剥夺，而特朗普政府已经请求最高法院解除这项禁令。

**经济与市场**

9月4日公布的八月非农就业数据大幅超出预期，成为当天所有市场波动的源头。美国八月新增就业十六万二千人，市场预期只有五万五千人，失业率维持在百分之四点一。有一个细节值得单独记：按美国全国广播公司财经频道对劳工统计局数据的分析，这十六万二千个新增岗位里有十五万八千个由女性获得，占比接近百分之九十八。

数据强劲反而压低了股市，原因是它让市场重新开始押注加息而不是降息。当天芝加哥商品交易所的联邦基金利率期货显示，交易员认为美联储在两周后的会议上加息的概率为百分之五十八。国债收益率随之跳升，三大股指全部收跌：道琼斯工业平均指数跌272点，合百分之零点五一，收于53414点；标准普尔五百指数跌百分之零点三八，收于7718.60点；纳斯达克综合指数跌百分之零点二九，收于26506.99点。

大众汽车9月3日晚间宣布的重组是这一天欧洲最重的一条消息。监事会一致通过的方案是到本十年末裁减十万个岗位，其中五万个是在此前已经谈定的五万个之外新增的，合计约占其全球员工总数的百分之十五，是全球汽车工业史上规模最大的一次重组。四家德国工厂的前景被明确列为不确定：埃姆登、茨维考、汉诺威，以及奥迪的内卡苏尔姆厂，公司表示在它们现有车型配额于2031年至2034年间陆续到期之后，无法为这些厂区争取到有竞争力的未来生产。方案同时要把车型数量减半，目标是到2030年实现九百万辆年销量与百分之九的营业利润率。促成这一步的是三重压力：美国关税、电动车需求不及预期，以及来自中国的竞争。

**科技与 AI**

OpenAI 在9月3日正式发布了代号 Astra 的 GPT-6，并从9月5日起向付费用户开放。它的上下文窗口为一百零五万 token，单次输出上限十二万八千 token，知识截止日期是2026年4月30日。定价是每百万输入 token 十美元、每百万输出 token 五十美元，缓存输入一美元，这使它成为 OpenAI 在公开接口上卖过的最贵的模型。发布采取分批推进的方式，第一天只开放给少量机构，随后依次是 ChatGPT 的 Plus、Pro、Business 与企业版，以及 OpenAI 接口和亚马逊云服务。此前披露过的两点现在可以对照着看：该模型的网络安全能力被内部评为关键级，而它采用的所谓循环深度架构会把一个问题在内部反复处理多轮，这让它的推理过程比传统的顺序推理更难被外部监测。

**科学与气候**

西班牙9月4日追平了本国九月的最高气温纪录，达到摄氏四十五点七度，同一天北非的沙尘飘到葡萄牙，当地卫生部门建议易感人群留在室内。联合国世界粮食计划署则给此前那份厄尔尼诺预报补上了一个具体的量：本轮厄尔尼诺预计至少持续到2027年2月，由此额外陷入严重饥饿的人口约为五千万。

尼泊尔与中国边境那场冰川洪水的统计仍在变动，9月4日的数字是接近一千二百八十人死亡、五千六百多人失踪。当天救援队从一条水电站隧道里活着救出两名工人，这是灾后多日来少见的好消息。

**社会与文化**

美国移民执法方面同一天有三条消息。五十一岁的中国公民魏连勇在北马里亚纳群岛被移民与海关执法局拘留数小时后死亡，他是2025年3月以来在该局与边境巡逻队羁押期间死亡的第五十七人。七十六岁的菲律宾裔绿卡持有者洛雷托·哈瓦尔在被关押两个多月后获释，他患有四期癌症。另有一名执法人员克里斯蒂安·卡斯特罗被以六项作出虚假陈述的罪名起诉，起因是他在明尼苏达州开枪打伤一名委内瑞拉移民，而联邦检察官否决了对他提出民权指控的动议。同日第三架遣返航班飞抵海地北部的海地角而非太子港，因为后者的机场已经不安全；海地的帮派暴力已造成一百五十万人流离失所。
