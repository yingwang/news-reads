# 2026-08-25 早间 brief

**地缘政治与国际关系**

美国对伊朗的金融攻势在 8月24日星期一由预告变成了具体动作。财政部长贝森特当日下午在华盛顿召开新闻发布会，宣布启动一项名为「经济弃儿行动」的制裁计划，并沿用了他此前在《金融时报》上使用的比喻，把它称作经济上的诺曼底登陆日。按他的说法，这项计划的目标是切断维系德黑兰政权的每一条经济命脉，直到伊朗孤立无援为止。

发布会真正的分量落在对第三国的警告上。贝森特要求各国切断与伊朗的经济往来，否则将面临反制，同时表示预计本周之内会宣布对某一家大型金融机构的制裁。他没有点名哪些国家可能被列入次级制裁，不过伊朗最大的几个贸易伙伴分别是中国、土耳其和阿拉伯联合酋长国。另一处值得记下的细节是，他给出了一个所谓的补救期，声称愿意给各方改正的机会，但这个窗口会关得很快。多家美国媒体的解读是，他公布了范围广泛的措施，却把其中最重的一击暂时搁置了。

与此同时，德黑兰在同一天从另一个方向作出了回应。伊朗议会国家安全与外交政策委员会于 8月23日星期日通过了《霍尔木兹海峡安全与发展战略行动计划》的第三条，随后在 8月24日对外披露。按照这一条款，伊朗将向获得其许可通行海峡的船只收取服务费，名目包括导航、环境支持、特定条件下的燃料供应、保险以及安全保障，费用可以用伊朗里亚尔支付，也可以用伊朗指定的其他货币结算。

这项安排并非全然新事。自今年三月起，伊朗方面已经在以个案方式收取费用，据报单船最高可达二百万美元；六月曾推出为期六十天的临时免收措施，该措施在八月中旬到期之后，收费重新回到台面上。真正的变化在于形式，把一种临时性的、逐船议价的做法写进法律条文，等于把一条水道从可以关闭的筹码改造成可以持续计费的通道。放在贝森特要切断伊朗一切收入来源的宣示旁边，两件事在同一天出现，构成了一组相当直接的对照。

**经济与市场**

美国股市在 8月24日星期一收盘涨跌互见。标准普尔 500 指数下跌 0.3%，道琼斯工业平均指数上涨 0.3%，纳斯达克综合指数下跌 0.8%。三大指数方向不一，说明当日的资金流动更多来自板块之间的调仓，而不是对某一宏观事件的整体反应。

更值得留意的是油价的走向。在贝森特宣布上述制裁的同一天，原油价格不升反降，长端美国国债收益率随之走低，美元对主要货币走弱。换句话说，交易员并没有立即把新一轮制裁理解为全球原油供应将再度中断的信号。这个反应与官方措辞之间的落差本身就是一条信息，它表明市场目前把「经济弃儿行动」看作对伊朗收入的打击，而不是对原油流量的打击。

接下来这一周还有两件事会牵动定价。7月个人消费支出物价指数将于 8月26日星期三公布，这是美联储最为看重的通胀指标；英伟达的季度业绩也排在本周，在人工智能相关资本开支持续扩张的背景下，这份财报的意义已经超出单一公司的范围。

**科技与人工智能**

亚马逊在 8月24日完成了对 OpenAI 的全部投资。此前该笔交易分为两部分，先期投入一百五十亿美元，余下的三百五十亿美元原本附有条件，包括 OpenAI 完成首次公开募股，或者在人工智能技术上取得突破。这两项条件均未达成，亚马逊仍然提前交割了余款，累计五百亿美元，取得约百分之五的股份。

围绕这笔投资的商业安排比金额本身更能说明问题。OpenAI 承诺采用两吉瓦的 AWS Trainium 算力，其中包括预计于 2027 年问世的 Trainium4 芯片；双方原有的云服务合约在八年期内追加一千亿美元；此外，AWS 将成为 OpenAI 面向企业的 Frontier 平台唯一的第三方云供应商。经过今年的多轮融资之后，OpenAI 的估值已经来到约八千五百二十亿美元。

中国这一侧同日也有两笔与算力有关的融资。阿里巴巴启动了规模八百亿港元、约合一百零二亿美元的配售，用途是芯片、基础设施以及模型的开发与部署；由于投资者认购踊跃，该次配售的规模在过程中被上调。阿里巴巴同时表示，其三年期资本开支计划已经使用了将近一半。另一笔来自小鹏汽车，其机器人业务完成首轮外部融资，金额超过九亿美元，投后估值超过六十三亿美元，由 IDG 资本与高榕创投领投，腾讯与阿里巴巴以战略投资者身份参与。该公司称这笔资金将用于人形机器人的研发与量产，以及物理人工智能模型的持续开发。

**科学与气候**

美国国家航空航天局的罗曼太空望远镜已通过最后阶段的发射准备审查，计划于 8月30日搭乘太空探索技术公司的猎鹰重型火箭升空。这台望远镜的主要科学目标是宇宙膨胀的历史与暗能量的性质，其视场远大于哈勃望远镜，因而能够在同等灵敏度下覆盖大得多的天区。

天文学的另一项进展来自星流观测。研究者在一个遥远星系周围识别出一条由恒星组成的暗弱条带，这是首次在银河系之外确认球状星团星流。此类结构由被潮汐力逐渐撕开的球状星团形成，其形状与分布可以用来反推所在星系的暗物质分布，因此在银河系之外找到同类样本，意味着这种方法有机会被推广到更广的范围。
