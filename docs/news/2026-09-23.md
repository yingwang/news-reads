# 2026-09-23 早间 brief

**地缘政治与国际关系**

第八十一届联合国大会的一般性辩论9月22日在纽约开幕，今年的主题是「恢复信任，驾驭变革」。秘书长古特雷斯开场就说「信任已经磨损」，把加深的地缘分裂、加剧的不平等、从遥远警告变成日常现实的气候危机，以及快到连开发者都措手不及的人工智能，并列为这一年的症结。按惯例第一位发言的巴西总统卢拉，把矛头指向安理会的瘫痪与否决权的滥用，并警告外部势力不得干预巴西10月4日的大选。这番话是在距投票只剩十二天、他与特朗普先后登上同一讲台的时候说的。

特朗普随后在联大把伊朗问题摆成了二选一：要么在中期选举之后达成协议，要么「消灭」这个伊斯兰共和国。美国公共广播公司的事实核查指出，他关于美国弹药储备取之不尽、截获了百分之九十七海上毒品，以及美国与委内瑞拉合计握有全球六成以上石油的说法都与现有数据不符，两国已探明储量合计约占全球的百分之二十一点九。与之相对地，路透社9月22日援引一名伊朗高级官员的话说，只要美国放松军事压力并解除对伊朗港口的封锁，德黑兰可以在七天之内重新开放霍尔木兹海峡，这一提议已经通过中间人转交华盛顿。

同样是9月22日，特朗普与丹麦、格陵兰两方领导人在联大场边签署安全协议。美国将扩建格陵兰西北部的皮图菲克太空基地，并在东部的梅斯特斯维格与南部的纳萨尔苏瓦克一带增设防务设施。特朗普称这让美国对格陵兰的安全拥有「永久控制」，协议文本则保留了丹麦与格陵兰的主权。几个月前他还扬言要夺取这座岛，如今是以签约的方式把驻军坐实。

中美之间，习近平9月23日至25日对美国进行国事访问，这是他2015年以来首次到访白宫。按白宫公布的日程，他23日抵达安德鲁斯联合基地，24日出席南草坪的欢迎仪式与国宴。路透社报道，习近平预计会援引1982年的《八一七公报》要求美国停止对台军售；雅虎财经援引的分析师则预期，会谈只会在稀土、人工智能与出口管制上小步推进。

欧洲这一侧，欧盟成员国代表9月22日同意把对俄制裁一次延长三年，不再每六个月续期，名单涵盖约三千个个人与实体，交换条件是把阿利舍尔·乌斯马诺夫与米哈伊尔·弗里德曼两位富豪移出名单。拉脱维亚最终弃权，协议才得以通过，乌克兰称此举「可耻」。战场上，俄罗斯9月21日夜间至22日凌晨动用二百一十二架无人机与多枚导弹，袭击了第聂伯罗、克里维里赫与巴甫洛格勒的工业设施，乌克兰最大的钢管生产商 Interpipe 在第聂伯罗的工厂有四人遇难。

**经济与市场**

美股9月22日涨跌互见：标普五百指数基本持平，纳斯达克综合指数涨百分之零点四，连续第二个交易日收在历史新高，道琼斯工业平均指数跌百分之零点三，报51,863.69点。油价的走向由霍尔木兹的消息决定：布伦特原油当天跌约百分之三，盘中一度跌到每桶97美元，是一周来首次跌破一百美元，而前一周它还接近110美元；美国西得克萨斯中质原油同样跌约百分之三。十年期美债收益率上午在百分之四点九五附近。科技股这一头，Meta 的人工智能代理 Muse 登上苹果应用商店榜首，股价9月21日大涨百分之十一，22日又涨百分之一点五。

东京股市9月21日至23日因敬老日与秋分连休，要到9月24日周四才重新开市。

监管这一侧，爱尔兰数据保护委员会9月21日以违反《通用数据保护条例》为由，对谷歌处以四亿零三百万欧元的罚款，问题出在2018年至2020年间谷歌对用户位置数据的处理，公司须在六个月内整改。这是该机构开出的第四大罚单。

**科技与人工智能**

OpenAI 9月22日发布 GPT-6 家族的两个新成员：面向编程与智能体任务的 Sol，以及面向摘要、信息抽取这类大批量轻任务的 Luna。公司称 Sol 的出错率约为上一代 GPT-5.6 Sol 的一半，可靠性接近本月3日发布的旗舰 Astra，而 API 价格降到前代的一半，Sol 为每百万输入与输出词元2美元与10美元，Luna 则是0.10美元与0.50美元。能力往上走、价格往下走同时发生，意味着月初还只有旗舰才做得到的事，到了月底已经进入平价档位。

同一天 OpenAI 还宣布，将允许第三方机构在模型训练与评估阶段就开展技术性安全评估，而不只是在上线之前，并列出安全论证、关键防护、能力评估与失准事件调查四个优先方向，正在与 METR、Redwood Research 等机构商谈。不过有报道指出，这份文件没有点名任何已确认的合作方，也没有写明访问条件，比奥尔特曼9月12日口头许下的「给评估者工位、工牌与电脑，并允许他们公开发现」要含糊得多。

另有一项机器人进展。麻省理工学院9月21日公布，一套基于人工智能的控制系统让其昆虫大小的扑翼飞行机器人速度提高约百分之四百五十、加速度提高约百分之二百五十，并能在十一秒内连翻十个跟头，偏离预定航迹不超过四到五厘米。研究者设想它将来能进入地震废墟这类常规无人机进不去的地方。

**科学与气候**

国际可再生能源署、第三十一届联合国气候大会主席团与全球可再生能源联盟9月21日在纽约气候周期间发布报告：全球可再生能源装机2025年底达到5.15太瓦，当年新增693吉瓦，创下纪录；可要在2030年把装机增至三倍、达到11.2太瓦，2026年至2030年每年平均要新增约1,200吉瓦，几乎是现有速度的两倍，电网投资每年也需要接近一万亿美元，是2025年水平的两倍以上。

哥伦比亚东北部的山火9月21日迫使当局宣布进入公共灾难状态，全国同时燃着近二十处火场，环境部长认为维拉德莱瓦附近那一场很可能是人为纵火。
