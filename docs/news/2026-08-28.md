# 2026-08-28 早间 brief

**科学与气候**

尼泊尔与西藏交界处发生了一场极其严重的冰川溃决洪水，这是过去两天全球最重的一条新闻。8月26日 清晨，喜马拉雅高处一段冰川崩塌，冰与岩石的混合体在下游堵住河道形成堰塞，随后一次性溃决，洪水沿吉隆藏布至特里苏里河一段约七十二公里的河谷倾泻而下，冲毁了尼泊尔拉苏瓦与努瓦科特两县的数十处聚落。有记录显示，某处河段的水位在半小时之内上涨了约八米。

伤亡数字仍在变动，截至 8月27日 的通报是尼泊尔境内确认死亡三百八十九人、失联九百一十人，中国境内死亡三人、失联五百五十八人。失联者中包含来自三十四个国家的旅行者至少六百六十八人，其中印度公民一百七十八人、美国公民六十五人、乌克兰五十三人、马来西亚五十一人、澳大利亚三十五人、英国三十三人、加拿大二十四人。

失联人数里外国公民占比如此之高，原因在于这条线路正是前往冈仁波齐与玛旁雍错朝圣的必经之路，八月又是朝圣旺季。据印度方面披露，仅在边境口岸的移民局一处，就有一个七十七人的朝圣团被洪水困住。此外，中尼之间重要的贸易与旅游通道吉隆口岸也在这次洪水中受损。

这类灾害在学术上被称为冰川湖溃决洪水，它的特点是几乎没有预警时间，而随着高山冰川在升温中加速消融，堰塞与溃决的频率正在上升。

**地缘政治与国际关系**

伊朗方面在核查问题上退了一步又进了一步。8月27日 传出消息，伊朗拒绝国际原子能机构的核查人员进入此前遭美国与以色列轰炸的核设施。这一举动的直接后果是，外界失去了评估这些设施实际受损程度的唯一独立渠道，而这恰恰是判断伊朗核计划究竟被推迟了多久的关键依据。

乌克兰方向的对抗在延续，并且新增了一层针对第三方的警告。乌俄双方 8月27日 仍在互相袭击，与此同时莫斯科方面公开警告英国不要向基辅提供武器。这条警告的时间点值得注意，前一日英国刚刚宣布将向乌方公开 SCALP 导弹中英国产部件的技术资料，以便乌克兰自行组装。

北美这一侧的贸易争端出现了一个象征性的升级动作。美国总统特朗普 8月27日 签署行政命令，指示联邦政府将安大略湖更名。此前一天他只是提出这个想法，如今落成了正式文件。这件事本身不改变任何贸易条件，但它说明这一轮争端已经从关税税率蔓延到了符号层面。

**经济与市场**

8月27日 美国股市在英伟达的带动下集体走高。标准普尔 500 指数上涨 0.7%，纳斯达克综合指数上涨 1.4%，道琼斯工业平均指数上涨约一百零五点。

主角毫无疑问是英伟达本身。前一日盘后公布的财报兑现之后，该股当日上涨接近 9%，创下自 2025 年 4 月以来的最大单日涨幅，市值一天之内增加四千四百二十亿美元。真正推动这个涨幅的并不是已经公布的季度数字，而是公司在电话会上给出的说法，即下一财年营收将增长约七成。这一句话的作用是打消了此前市场最大的担忧，也就是各类专用处理器的竞争是否已经开始侵蚀英伟达的需求。

同业的反应并不一致。博通当日上涨 4.49%，超威半导体反而下跌 0.89%，说明资金并没有笼统地买入芯片板块，而是集中押注数据中心这一条线。软件那一侧，Salesforce 与 CrowdStrike 因各自给出稳健的业绩指引而领涨。

当天公布的初请失业金人数进一步印证了就业市场的韧性。市场接下来的焦点是美联储主席沃什将于 8月28日 在杰克逊霍尔发表的讲话。

**科技与人工智能**

Meta 与美国多个州及哥伦比亚特区就社交平台危害未成年人一案达成和解，代价是最高一百八十亿美元，以及一整套对产品本身的强制改造。

赔付结构值得单独说明，因为它解释了为什么不同报道给出的数字并不一致。其中七成、约一百二十七亿美元将在未来十年内支付，这部分是确定的；剩下三成则附带条件，只有当 Snapchat、TikTok 与 YouTube 也采取同等的安全措施并向各州支付相应份额时，Meta 才需要付出。

产品层面的改动才是这份和解真正的分量所在，适用对象是十三至十七岁的用户。这一年龄段在脸书与照片墙上的合计使用时长将被限制为每日两小时，且该设置只有在家长许可下才能更改；午夜至清晨六点之间平台将禁止未成年人登录，但私信除外；在正常上课时间内不得向未成年人推送通知；此外，未成年人内容的点赞数将默认关闭，那些被称为极端美颜的滤镜也将被移除。

按照目前的时间表，如果和解获得批准，其中一部分改动会在四到六个月内落地，包括面向未成年人的非个性化信息流；而年龄验证系统的改造预计需要一年左右。
